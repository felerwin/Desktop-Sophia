SEND TO SOPHIA'S TUBE - CHROME EXTENSION
========================================

INSTALL ONCE
------------
1. In Chrome, open: chrome://extensions/
2. Turn on Developer mode in the upper-right corner.
3. Click "Load unpacked".
4. Select this chrome_extension folder.
5. Pin "Send to Sophia's Tube" from Chrome's Extensions menu.

USE IT
------
1. Start Sophia so her dashboard is available.
2. Open a YouTube video.
3. Move the video to the exact moment you want as its starting cue.
4. Click the extension button.
5. Sophia's Tube form opens with the URL, title, and current playback time filled in.
6. Add when Sophia should use it, then click "Save video".

Clicking the extension away from YouTube simply opens Sophia's dashboard.
