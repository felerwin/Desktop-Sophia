# Bundled speech models

`silero_vad.onnx` is the official Silero VAD v6.2.1 ONNX model from
https://github.com/snakers4/silero-vad.

- License: MIT
- Copyright: 2020-present Silero Team
- SHA-256: `1A153A22F4509E292A94E67D6F9B85E8DEB25B4988682B7E174C65279D8788E3`

It is used locally for streaming voice-activity detection. No audio is sent to
Silero and the model does not require network access at runtime.
