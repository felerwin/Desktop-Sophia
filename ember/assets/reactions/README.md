# Static reaction assets

Each PNG is an independent 192×208 transparent Ember pose. Emotional reactions load
these files directly. Idle and walking frames live under `../animations`; the legacy
sprite atlas is not cropped at runtime.

Semantic reactions:

- `idle.png`
- `listening.png`
- `thinking.png`
- `speaking.png`
- `amused.png`
- `excited.png`
- `concerned.png`
- `startled.png`
- `moving-left.png`
- `moving-right.png`
- `laughing.png`
- `facepalming.png`
- `embarrassed.png`
- `shy.png`
- `worried.png`
- `crying.png`
- `smug.png`

The sixteen `look-*.png` files cover directions in 22.5-degree increments from 0
through 337.5 degrees for deliberate pointing and screen focus.
